# 비대칭 드로잉 FPS — 브라우저 프로토타입 v0.1

술래 1명이 도화지에 그린 그림이 3D 전장의 몬스터가 되고, 플레이어 1~4명이 10분을 버텨 탈출하는 비대칭 멀티플레이 FPS입니다.
기획안: [`docs/gdd_v1.1.md`](docs/gdd_v1.1.md)

## 플레이

- **방 만들기**: 방 코드 5자리가 생깁니다. 친구에게 알려주세요. 방을 만든 PC가 게임 계산(방장)을 맡습니다.
- **참가**: 방 코드를 넣고 참가합니다. 2~5명.
- **혼자 테스트**: 술래와 플레이어를 혼자 오가며 시험합니다 (Tab 으로 화면 전환).
- PC 전용(키보드·마우스). 크롬·엣지 권장.

| 역할 | 조작 |
| --- | --- |
| 플레이어 | WASD 이동 · Shift 달리기 · Space 점프 · 클릭 사격 · R 재장전 · G 지우개 수류탄 · E 길게 부활 |
| 술래 | 지도 클릭 = 소환 위치 · 도화지에 그리기 · 1~5 색 · E 지우개 · Ctrl+Z 되돌리기 · Enter 소환 |

## v0.1 에 들어간 것

- 술래 화면 2분할: 탑뷰 관전 + 도화지·5색·연필 잉크·판정 미리보기·보스/올인·재소환 슬롯 3칸
- 판정: 칠한 면적 기준 색 → 속성(반반이면 2개), 형태 → 비행·돌진·원거리, 스탯 공식
- 소환: 플레이어 8m 금지, 3초 빨간 장판, 보스 경고(사이렌·붉은 화면), 보스 재사용 60초
- 몬스터: 종이 인형 빌보드 + 흰 테두리 + 속성 오라, 가장 가까운 플레이어 추적, 근접·돌진·원거리
- 플레이어: 총 1종(30발·무한 재장전 1초), 지우개 수류탄, 부활(60초 뒤·2초·HP 50%·횟수 제한), 2인전 목숨 2개
- 10분 타이머, 1분 남음, 30초 전 탈출 문 예고, 문 열림 + 최후 발악(잉크 무제한), 탈출 = 승리
- 이탈: 술래가 나가면 플레이어 승리, 플레이어가 모두 나가면 술래 승리
- 멀티플레이: PeerJS(WebRTC) P2P — 서버 설치 없이 GitHub Pages 에서 동작

## 아직 안 들어간 것 (다음 단계)

보급 카드(3분마다), 봇·AI 술래, 명예 투표·갤러리, 무기 레이어, 신고·그림 숨기기, 맵 2·3, 핑 기준 방장 자동 선택·방장 이전, 진짜 3D 캐릭터 모델

## 개발

```bash
npm test                 # 판정·서버 로직 테스트 (설치할 것 없음)
python3 -m http.server 8080   # http://localhost:8080 에서 실행
```

- 구조와 SOLID 원칙: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- 밸런스 수치는 전부 [`src/config/balance.js`](src/config/balance.js) 한 곳에 있습니다.
- 빌드 도구 없음. ES 모듈 그대로 GitHub Pages 에 올라갑니다. three.js·PeerJS 는 `vendor/` 에 들어 있습니다.

### 연결에 대해

- 접속 중개는 PeerJS 공개 서버(0.peerjs.com)를 씁니다. 연결이 맺어지면 데이터는 PC끼리 직접 오갑니다.
- 일부 회사·학교 네트워크에서는 직접 연결이 막힐 수 있습니다 (PeerJS 기본 TURN 중계로 시도).
- 방장 창은 앞에 띄워 두세요. 브라우저가 뒤로 간 탭의 타이머를 느리게 돌려서 다른 사람 화면이 끊겨 보일 수 있습니다.
