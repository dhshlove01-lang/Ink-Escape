# 아트 방향: "선 없이 자연스러운, 다크한 마왕의 방" (2026-11-27 정리 — 다음에 이어서)

## 목표 (사용자)
- 참고 그림: `art/style/reference/stylized_mood_ref.jpg` (스타일라이즈드 판타지 — 손으로 칠한 텍스처, 두툼한 형태, 차가운 밤빛 + 따뜻한 등불).
- "이런 게임은 선이 없어도 자연스럽다. 딱 이런 분위기를 원한다. 좀 더 다크한 마왕 방이면서."
- → 잉크 외곽선에 기대지 말고 **조명·공기감·형태·밀도·후처리**로 분위기를 만든다.

## 참고 그림이 좋아 보이는 이유 (분석)
1. **차가운 색과 따뜻한 색의 대비**: 전체는 어두운 푸른 밤빛, 등불 주변에만 주황빛이 고인다. 지금 우리는 반구광 하나로 전체를 고르게 밝혀 밋밋하다.
2. **공기감**: 멀수록 푸르고 흐린 안개, 실루엣으로 겹치는 배경 → 깊이. 지금 궁전은 사방이 벽이라 원경이 없다.
3. **두툼한 형태**: 기와·난간·돌계단이 전부 모서리가 깎이고 낡은 입체. 우리 벽은 텍스처 입힌 평평한 상자.
4. **밀도**: 화면 어디나 소품·구조물. 우리 홀은 빈 바닥이 넓다.
5. **후처리**: 등불의 은은한 번짐(블룸), 색 보정, 가장자리 어둡게(비네팅).

## 지금 상태 (2026-11-27 기준, 바꾸기 전 출발점)
- 렌더: `src/client/render/InkRenderer.js` — 셀 셰이딩(툰 3단) + 잉크 외곽선 + 종이 결. 그래픽 '보통·높음'에서 켜짐, '끄기'(`graphics.js` `low`)에서 꺼짐.
- 조명: 진짜 빛 2개뿐 — 반구광 + 위쪽 키 빛 (`config/themes.js` `palace.hemi` 5.2 따뜻한 색, `key`). 횃불·샹들리에·문은 빛무리 그림만 (`SceneBuilder`, `PalaceBuilder`, `DungeonKit.buildTorch`).
- 성능: 잉크 켬 한 프레임 그리기 74번·삼각형 25만 (헤드리스 측정), 자동 해상도(`GraphicsSettings.frame`), F3 성능 표시.
- 맵: 원통형 궁전 (`shared/map/maps.js buildPalace`), 텍스처 `assets/tex/palace_*` (사용자가 잉크 느낌으로 바꿀 예정이었음 — 이 문서 방향과 함께 다시 정할 것).

## 할 일 (순서)

### 1단계 — 분위기 조명 (코드만, 가벼움)
진짜 조명을 늘리지 않고 **가짜 빛**으로 (조명 수 = 픽셀마다 계산량이라 2개 유지).
- 바탕: 짙은 보라·남색 그림자 (반구광 색을 차갑게, 세기는 지금보다 낮게).
- 따뜻한 빛 웅덩이: 횃불·샹들리에·창 아래 바닥과 벽에 주황·진홍 빛 그림(가산 합성 원형 판). 횃불 빛무리는 이미 있음 → 바닥 웅덩이만 추가.
- 스테인드글라스 빛줄기: 창에서 바닥으로 비스듬한 반투명 판 (가산, 깊이 안 씀).
- 떠다니는 불티: 붉은 점 입자 몇십 개 (몬스터 오라처럼 Points, 텍스처 있는 동그란 점).
- 바닥 쪽 붉은 안개: 높이 안개 느낌 (바닥 근처 반투명 판 여러 장 또는 셰이더 안개).
- 어디에: `config/themes.js` 테마 값(색·세기·안개) + `render/PalaceBuilder.js`(빛 웅덩이·빛줄기·불티 배치, 맵 데이터 `torches`·`props` 자리 사용).

### 2단계 — 후처리 (화면 처리 한 번)
- 블룸(밝은 곳 번짐: 불꽃·빛무리·창), 톤 매핑(ACES), 색 보정(그림자 푸르게·밝은 곳 따뜻하게), 비네팅.
- `InkRenderer` 의 합치기 단계에 넣거나, 선 없는 기본 렌더용 `PostRenderer` 를 따로 만든다 (SRP). 블룸은 절반 해상도 흐림 2번 정도로 가볍게.
- 그래픽 '끄기' 에서는 후처리도 끈다.

### 3단계 — 잉크 선·셀 명암을 옵션으로
- 기본: **선 없음 + 셀 명암 없음**(원래 PBR 재질, 1·2단계 분위기).
- 그래픽 창에 '잉크 스타일' 켬/끔 따로 (지금 `graphics.js` 의 `ink` 를 단계와 분리).

### 4단계 — 형태와 밀도 (3D 에셋, 사용자가 Tripo 로)
필요한 조각 (두툼하고 모서리 깎인 스타일, 다크 마왕 궁전):
- 벽 아래 받침(걸레받이) · 벽 위 장식 띠(코니스) — 길게 반복할 모듈 조각
- 기둥 사이 아치 · 벽 기둥(반쯤 박힌 기둥)
- 왕좌 단상 계단(넓은 계단 + 양옆 난간)
- 해골 무더기 · 사슬 무더기 · 촛대(촛농 흐른 큰 초 여러 개) · 깨진 석상 · 금화/보물 더미
- 바닥 장식: 큰 원형 문양 판, 깨진 바닥 조각
- 원경: 높은 창 밖으로 보이는 붉은 하늘·첨탑 실루엣(배경 그림 한 장이면 충분)
배치는 `shared/map/maps.js buildPalace` 의 `props`(충돌 `solid`·`h` 포함) + `config/models.js prop()` 한 줄씩. 3D 부족 목록은 `HANDOFF.md` "3D 오브젝트 부족 목록" 에도 있음.
